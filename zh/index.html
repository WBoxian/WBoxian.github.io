CHAPTER 02 / PROJECT

个人项目

从数据准备到线上服务的一次完整系统实践。

个人项目 · 独立完成11/2025 — 05/2026

小红书麒麟 QILIN

搜索推荐一体化系统

基于约 200 万笔记、1.5 万用户数据，完成数据预处理、特征工程、多路召回、排序模型训练、线上部署与在线服务。

200万笔记数据
1.5万用户数据
15万搜索与推荐样本
约 150ms线上服务延迟
  1. 01数据预处理
  2. 02特征工程
  3. 03多路召回
  4. 04粗排 / 精排
  5. 05在线服务

实现要点

  • 召回：DSSM 双塔 + Faiss，融合 Swing 与 UserCF 多路策略。
  • 排序：LambdaMART（LightGBM / XGBoost）粗排，DIEN 建模用户序列兴趣进行精排。
  • 服务：FastAPI + Redis，支持实时行为写回与搜索推荐联动。
