工作流

独立完成从数据预处理、特征工程、多路召回、粗排、精排到线上部署与在线服务的全流程闭环， 在统一框架下对搜索与推荐场景做差异化建模。

模型架构

召回侧融合 DSSM 双塔 + Faiss、Swing、UserCF；粗排采用 LambdaMART (LightGBM / XGBoost)；精排采用 DIEN 建模用户序列兴趣。

在线服务

基于 FastAPI + Redis 搭建，支持实时行为写回更新与搜推联动，线上延迟稳定在约 150ms。
